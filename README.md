# 🏋️ AI Gym Coach

🚀 **Live App:**  
👉 https://ai-gym-coach-324.streamlit.app/

> ℹ️ The app may take a few seconds to load if it has been inactive.

An AI-powered real-time gym trainer that uses computer vision to track exercises, count repetitions, and provide workout feedback.

## ✨ Features

- 🎥 Real-time exercise tracking
- 🔢 Automatic repetition counting
- 🧍 Pose detection using MediaPipe
- 📊 Workout tracking
- 🤖 AI-powered workout assistance
- 🌐 Streamlit-based interface

## 🛠️ Tech Stack

- Python
- Streamlit
- MediaPipe
- OpenCV
- Pandas
- Groq
- gTTS
